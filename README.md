# Проверка контрагентов

ИИ-помощник для анализа компаний под конкретную сделку: поиск, сравнение,
уточняющие вопросы и выводы с источниками. Есть память условий и проекты с документами.

## Запуск

Нужны Python 3.12 и uv. При первом запуске создайте `.env` по
[образцу](.env.example), если его ещё нет, и укажите:

- `COUNTERPARTY_SNAPSHOT_JSON_PATH` — путь к JSON с отчётами;
- `COUNTERPARTY_LLM_API_KEY` — ключ модели для свободных запросов и AI-диалога.

Адрес и модель задаются через `COUNTERPARTY_LLM_BASE_URL` и `COUNTERPARTY_LLM_MODEL`.
Не добавляйте `.env`, исходные отчёты и персональные данные в Git.

```bash
uv sync
uv run python src/main.py
```

Откройте [localhost:8000](http://127.0.0.1:8000). Остановка — `Ctrl+C`.
Если порт занят: `COUNTERPARTY_PORT=8011 uv run python src/main.py`.
Активировать `.venv` не нужно; готовый интерфейс уже включён в репозиторий.

## Как пользоваться

1. Введите ИНН, ОГРН, название или просьбу сравнить несколько компаний.
2. Укажите цель и условия сделки — сразу или в ответ на уточнение.
3. Получите краткий анализ; раскройте отчёт и источники при необходимости.
4. Задавайте вопросы и меняйте условия: помощник учитывает их в текущей проверке.
5. При необходимости сохраните проект, добавьте договор и подтвердите итоговое резюме.

Enter отправляет сообщение, Shift+Enter переносит строку. Чат можно расширить.

LLM понимает запрос, выбирает разделы и формулирует ответ. Поиск, расчёты и проверку
источников выполняет код. Узкие вопросы используют готовые факты.
Без ключа доступны карточки и сравнение по явным реквизитам.

Это локальный прототип: отчёты не обновляются из банковских систем, MCP не подключён.
Банковский светофор не пересчитывается; отсутствие данных не означает отсутствие риска.
Ответы требуют критической оценки и не гарантируют безопасность сделки.
Запросы и отобранные факты передаются настроенному LLM-провайдеру.

## Стек и структура

Python 3.12, uv, FastAPI, LangGraph, Pydantic, SQLite, RapidFuzz;
React, TypeScript, Vite и Recharts. SQLite хранит сессии и проекты, отчёты читаются из JSON.

- `src/main.py` — единый запуск.
- `src/counterparty_agent/` — данные, аналитика, AI, граф, API и проекты.
- `frontend/src/` — интерфейс; сборка — `src/counterparty_agent/ui/build/`.
- `tests/`, `benchmarks/` — регрессии и живые прогоны моделей.
- `docs/`, `artifacts/` — документация и материалы кейса.

## Разработка

Проверки backend из корня репозитория:

```bash
uv run ruff check .
uv run mypy
uv run pytest
```

После изменений интерфейса нужны Node 22+ и pnpm:

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm test
pnpm build
```
