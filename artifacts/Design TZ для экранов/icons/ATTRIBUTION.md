# Alfa/Core DS icon attribution

The SVG files in `icons/` are unmodified copies from the official
[core-ds/ui-primitives](https://github.com/core-ds/ui-primitives) repository,
directory `icons/glyph`, commit `9587916dcae6073cc49e572614a556b1baf210ae`
(2026-09-01).

The repository's `package.json` declares license MIT, package `ui-primitives`
version 35.68.0, and author Design System Team. The checked revision does
not contain a standalone LICENSE file, so a production team should retain
this attribution and verify the applicable internal/open-source policy before
shipping.

Local filenames omit only the upstream `glyph_` prefix. SVG content is unchanged
(originals also kept at `icons/glyph/glyph_*.svg`).

The React wrappers are generated by the official
[core-ds/icons](https://github.com/core-ds/icons) repository and published as
[`@alfalab/icons-glyph`](https://www.npmjs.com/package/@alfalab/icons-glyph).
At research time (2026-09-03), both the repository package manifest and npm
reported version 2.289.0, licensed MIT.

## Использование в макете

`icons/paths.json` — те же path-данные с `fill="currentColor"` для встраивания
в разметку прототипа (цвет задаётся через CSS `color`). Это производная копия
для прототипирования, а не подмена исходного файла: неизменённые оригиналы с
`#000000` / `#0B1F35` лежат рядом.

В разработку идут React-компоненты из `@alfalab/icons-glyph` по прямым путям
импорта, а не эти SVG.

| Кнопка «К сравнению» | `ArrowsUpDownMIcon` + `OfficeMIcon` (fallback-композиция) |
| Evidence drawer, блок значения | `DocumentLinesLineMIcon` |
| Фильтр столбцов | `FilterMIcon` |
| «Требует проверки» во всех ячейках | `ExclamationCircleMIcon`, уровень — цвет + текст |

StatusBadge, цвет — состояние компонента, смысл несёт текстовый уровень рядом.

Галочка внутри Checkbox остаётся собственной отметкой компонента, а не иконкой
из набора: в core-components она рисуется средствами самого чекбокса.
