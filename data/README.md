# Данные

Папка предназначена для локальных входных снимков, которые не попадают в Git.

- Основной источник MVP — выданный реальный JSON. Путь задаётся через
  `COUNTERPARTY_SNAPSHOT_JSON_PATH`; копировать файл сюда необязательно.
- Интеграционные тесты работают с тем же JSON и пропускаются, если путь не
  настроен. Отдельная синтетическая база компаний не используется.
- CSV остаётся резервным форматом для следующего этапа.
- Исходные snapshots, SQLite сессий, секреты и PII нельзя коммитить или
  выводить в логи.

Полученные файлы: `contractors_audit.snapshot.json` и
`contractors_audit.snapshot_C12613591.csv`. Происхождение материалов описано в
[`artifacts/INDEX.md`](../artifacts/INDEX.md), без копирования исходных данных в Git.
