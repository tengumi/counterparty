# Данные

Папка для локальных снимков и обезличенных тестовых наборов данных.

Что осталось сделать:

- основной демонстрационный источник — вложенный `snapshot.json`;
- CSV используется как резервный формат и для проверки совместимости;
- исходные файлы, SQLite сессий и персональные данные не коммитятся;
- для тестов подготовить небольшой синтетический набор данных без реальных ФИО,
  телефонов, адресов и идентификаторов физических лиц.

Выданные файлы называются `contractors_audit.snapshot.json` и
`contractors_audit.snapshot_C12613591.csv`. Они намеренно не перенесены в Git;
локальную копию следует хранить в этом каталоге. Описание происхождения
материалов находится в [`artifacts/INDEX.md`](../artifacts/INDEX.md).
