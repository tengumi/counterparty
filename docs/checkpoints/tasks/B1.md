## Готово

- Самостоятельный uv-проект `services/ui_api` (Python 3.13, hatchling,
  локальная зависимость `counterparty-contracts` через `tool.uv.sources`).
- FastAPI composition root `create_app()` с явным lifespan, помечающим
  готовность приложения.
- Typed `/healthz` с pydantic-моделью, 503 при неподнятом lifespan и версией
  установленного пакета контрактов; ответ виден в OpenAPI.
- Собственный Dockerfile: build context — корень монорепы, venv собирается сразу
  по финальному пути `/app/.venv`, запуск от непривилегированного пользователя.
