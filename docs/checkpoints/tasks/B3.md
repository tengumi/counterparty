## Решения и допущения

- Штатный stateless Streamable HTTP; ручной MCP protocol не пишется.
- `stateless_http` в текущем FastMCP задаётся в `http_app()`, а не в конструкторе
  `FastMCP` — конструктор такой аргумент больше не принимает.
- Docker build context — корень монорепы, иначе локальную зависимость
  `packages/contracts` собрать нельзя; Dockerfile остаётся внутри сервиса.
- Envelope-модели живут локально в сервисе: shared-контракт MCP-ответов пока не
  зафиксирован в `packages/contracts`.

## Ограничения V05

- Reports repository не подключён: stub всегда возвращает `unavailable` с
  `dependency_unavailable`; `not_found` появится вместе с реальным репозиторием.
- Stateless-режим проверен только in-process клиентом FastMCP; multi-worker
  и reconnect-поведение под нагрузкой не проверялись.
- Container startup/health проверен только сборкой образа, без запуска.
