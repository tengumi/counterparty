## Решения и допущения

- Матрица версий (проверена): python `assistant-stream==0.0.36` ↔ npm
  `assistant-stream@0.3.41` (транзитивно) ↔ `@assistant-ui/react@0.15.18`
  (+ `@assistant-ui/core@0.3.17`). Обязателен
  `protocol: "assistant-transport"`: по умолчанию runtime берёт `data-stream`
  decoder, который наш SSE не разберёт.
- Публичная проекция едет только через `update-state` operations; сообщения
  строит converter. Сегменты path — строки, включая индексы списков.
- Списки растут через append-item (проксирование `list.append`): адресация
  индекса `len(list)` напрямую запрещена proxy-объектом библиотеки.
- `useAssistantTransportState` в 0.15.18 бросает на первом рендере рядом с
  runtime (thread-list отдаёт placeholder extras). Используем свой
  `useAgentProjection` поверх публичного `useAuiState`.
- `onCancel` вызывается ещё и после ошибки (с `error`): в этом случае run уже
  терминальный и переименовывать его в cancelled нельзя.
- Новых DTO в packages/contracts не добавляли: проекция локальна в
  services/agent, переиспользует RunInfo/Error/RunStatus/identifiers.
