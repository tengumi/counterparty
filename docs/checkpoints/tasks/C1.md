## Решения и допущения

- Матрица версий: python `assistant-stream==0.0.36` (encoder
  `AssistantTransportResponse`) ↔ npm `assistant-stream@0.3.41`
  (`AssistantTransportDecoder`) ↔ `@assistant-ui/react@0.15.18`
  (`useAssistantTransportRuntime`, `protocol: "assistant-transport"`).
  У пары есть официальный interop-фикстур в npm-пакете, диалекты совпадают.
- Публичная проекция передаётся только через `update-state` operations
  (`controller.state`), сообщения строятся converter'ом на фронте.
  Terminal error — `controller.add_error` (chunk `error`).
- Новые общие DTO в packages/contracts не добавляем: проекция объявляется
  локально в services/agent, переиспользуя RunStatus/ErrorCode/identifiers.
