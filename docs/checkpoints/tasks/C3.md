## Решения и допущения

- domain подключил contracts как локальную зависимость и переиспользует
  `Availability`, `EvidenceKind`, `EvidenceRef` вместо дублирования.
- ОГРН: первая цифра ограничена {1,2,3,5} для 13-значного и {3,4} для
  15-значного; при расхождении с fixture правило меняется в одном месте.
- КПП контрольной суммы не имеет — проверяется только форма (4 цифры + код
  причины из [0-9A-Z] + 3 цифры).
- ИНН из одних нулей формально проходит арифметику, но помечается `all_zeros`.
- `pathlib` исключён из purity-списка: его тянет pydantic как тип, не как I/O.
