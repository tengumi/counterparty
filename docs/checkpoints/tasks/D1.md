## Решения и допущения

- `FactValue` — API-проекция `FactSlot`: available обязано нести значение и
  минимум один evidence ref; missing/present_empty/invalid/restricted значение
  не несут; ноль — обычное available-значение.
- Деньги — `Decimal`, `float` отвергается на входе; wire-форма — plain-строка
  без разделителей и экспоненты.
- `$date` источника остаются `UtcDatetime` (`registration_date`, `status_date`,
  `issue_date`, `start_date`/`end_date`, `started_at`); `ValueType.DATE` — это
  календарный день слоя отображения.
- ZSK: `raw_value` хранится как есть; подтверждён только `GREEN → positive`
  (`ZSK_CONFIRMED_DISPLAY_LEVELS`), всё остальное, включая неизвестный токен, —
  `neutral` с обязательным `display_note`.
- `SECTION_SOURCE_KEYS` покрывает все секции `REPORT_SECTIONS` импортёра;
  `arbitration` намеренно указывает два ключа источника.
- `SECTION_RECORD_KINDS` ограничивает записи каждой секции; секция без своего
  типа записи (`status`, `coefficients`, `founders`, `tax_systems`, `contacts`,
  `branches`, `zsk`) обязана вернуть пустой `records`.
- `Project` наследует `ProjectEnvelope`, `ThreadSummary` — алиас
  `ThreadEnvelope`: имена contract v0 не переизобретаются.
