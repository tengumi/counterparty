## Решения и допущения

- Роли создаются `NOLOGIN` как групповые: логин-пользователь и пароль создаёт
  деплой, репозиторий их не хранит.
- Привилегии на framework-owned checkpoint storage (LangGraph) сюда не входят:
  их namespace создаёт владеющая библиотека на своём шаге деплоя.
- Роль `agent` не имеет никаких привилегий на `reports` — факты отчёта она
  получает через MCP — и в `workspace.threads` может изменить только колонку
  `last_activity_at`.
- Тестам нужны разные базы для `packages/storage` и `migrations`: сессионная
  фикстура storage пересоздаёт схемы и оставила бы `alembic_version` из другой
  базы рассогласованным.
