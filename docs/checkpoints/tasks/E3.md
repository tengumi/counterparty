## Решения и допущения

- Модуль назван `diagnostics.py`, а не `warnings.py`: файл с именем стандартного
  модуля в каталоге пакета ломает запуск скриптов из этого каталога.
- `WarningCode.UNSPECIFIED` существует специально для строковых warnings
  `counterparty_domain`: категория не угадывается, текст не теряется.
- `PendingQuestion` — минимальный DTO `{id,text,asked_at,evidence_refs}`;
  статус вопроса в Specs не закреплён и не выдуман.
- Demo-вход не проверяет пароль (это демонстрация и помечено `demo: true`), но
  сессия серверная, а проверка владения проектом настоящая; чужой проект даёт
  `not_found` с тем же сообщением, что и несуществующий.
- Схемы `workspace` нет, поэтому владение читается через порт
  `ProjectDirectory`; in-memory реализация заменяется repository без правки
  зависимостей.
- Ownership-зависимости проверяются в тестах через probe-маршруты: бизнес-
  endpoint'ы сверх API-01 намеренно не добавлялись.
