## Решения и ограничения

- Native test/demo окружение под `/tmp` временное. Для Cyrillic case-insensitive search нужна Unicode-aware `LC_CTYPE`; `C` непригоден, UTF8 encoding сам по себе недостаточен.
- G4 оставляет `stale_after=None`: возраст запроса не доказывает остановку worker; crash recovery требует отдельного fencing/reconciliation решения.
- Docker отсутствует; Dockerfiles не менялись, Docker/Compose runtime не проверялся.
- Runtime PostgreSQL оставлен для G6 review, не останавливать до завершения его smoke. Затем: `pg_ctl -D /private/tmp/g5-pgdata stop -m fast`.
