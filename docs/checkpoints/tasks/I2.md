## Решения и допущения

- Env: `MCP_DATABASE_URL`, `MCP_AUTH_TOKEN_SHA256` (64 lower-case hex; digest of
  high-entropy server-side Bearer credential), `MCP_MAX_CONCURRENT_READS` (5),
  `MCP_READ_TIMEOUT_SECONDS` (10), `MCP_MAX_RESPONSE_BYTES` (65536 JSON envelope bytes).
- Runtime: `uv run uvicorn counterparty_mcp.app:app --host 127.0.0.1 --port 8002`;
  `/healthz` is process liveness, tool access requires provisioned Bearer credential.
- Credential rotation is server configuration + restart; external OAuth and
  compare_companies remain outside MCP-01/02.
- Auth API: https://gofastmcp.com/servers/auth/token-verification (2026-09-05);
  standard TokenVerifier extension, no custom MCP protocol or auth middleware.
