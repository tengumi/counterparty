## Решения и допущения

- Локальные path-пакеты: non-editable + явный `--reinstall-package` для
  counterparty-contracts/domain/storage во всех sync-шагах (Dockerfile и compose).
- Единый edge на :5173 (`deploy/proxy/nginx.conf`): browser видит один origin,
  cookie остаётся first-party, SPA собирается без API base URL и без секретов.
- MCP получает только SHA256 digest; agent получает исходный токен на backend.
  README описывает совместную ротацию. Образ agent именуется по Compose project.
- Parity доказывается live-тестом `services/mcp/tests/test_parity.py` по HTTP,
  без импорта UI API.
