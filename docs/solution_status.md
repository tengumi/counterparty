# Текущее состояние решения

## Аннотация и задача

Рабочее пространство помогает сравнить известных контрагентов, сократить ручной
отбор и уточнить существенные факты перед сделкой. Вместо последовательного чтения
отчётов пользователь получает таблицу, связанный чат и сохранённый проект проверки.
Гипотеза ценности — меньше времени на сопоставление и больше повторных обращений;
рост retention пока не измерен.

## Реализовано

- Поиск по ИНН/ОГРН/названию с подтверждением неоднозначности.
- Карточка, единая матрица N компаний, фильтры, различия и ручной отбор.
- React-интерфейс с источниками в отдельной панели без технического JSON.
- AI-диалог по компании и группе, фокус и память сессии.
- Сохранённые проекты: цель, отбор, план трёх чтений, документы, открытые вопросы.
- Предложение резюме с diff; сохранение только после подтверждения пользователя.
- Разделение Python и frontend по предметным модулям; единый запуск через uv.
- Синтетические проверки N до 100, evidence, пропусков, изоляции и версий проекта.

Расчёты выполняет код; AI выбирает разрешённые факты и темы плана. Банковский
сигнал неизменяем. Без модели доступны карточка, сравнение и обозначенный базовый
план. Подключение модели сохранено, названия сервиса убраны из продукта.

## Техническое решение

Python 3.12/uv, FastAPI, Pydantic, LangGraph, Decimal, RapidFuzz;
React/TypeScript/Vite с базовыми Alfa Core Components.
Отчёты — локальный JSON. SQLite используется только для памяти и проектов.
Данные через БД и MCP намеренно не добавлены в эту итерацию.

## Результаты и ограничения

Реализован путь «сравнение → финалисты → цель → план → документ → подтверждённое
резюме». Автоматические проверки не заменяют оценку заказчиком.
Детали прогона: [бенчмарк](../benchmarks/README.md).

Нет банковской интеграции, общего AI-скоринга, автоматического победителя,
подбора аналогов, OCR и юридического заключения. Работа ограничена доступными
разделами snapshot; выбор релевантных фактов моделью может ошибаться.
Документы читаются ограниченными фрагментами, а не анализируются исчерпывающе.
Локальная cookie-изоляция не заменяет production-авторизацию.
