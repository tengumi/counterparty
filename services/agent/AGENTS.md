# Проверки Agent Service

Решение пользователя от 06.09.2026: не писать и не восстанавливать хрупкие
автотесты конкретного поведения агента, в том числе на scripted/deterministic
моделях. Не фиксировать точные ответы, промпты, форматирование, выбранные
справочные заметки, порядок/число вызовов tools и сценарные реакции модели.
Не переносить такие тесты в другие каталоги или eval-наборы.

Сохранять общие устойчивые проверки: HTTP/RPC и streaming contracts,
checkpoint/persistence, конфигурация, изоляция tenant/project/thread,
разрешимость evidence refs, границы файлового доступа и защита секретов.
Чистые расчёты и валидация могут проверяться обычными тестами.

Поведение модели проверять ручным живым прогоном при необходимости.
Правки промпта, справочника и агентного сценария не требуют новых автотестов.
Для оставшихся общих проверок запускать `uv run ruff check .`,
`uv run ruff format --check .`, `uv run mypy` и `uv run pytest`.
