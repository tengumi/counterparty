# Тесты

`test_scaffold.py` проверяет импорт пакета и наличие основных сценариев интерфейса и API.
`test_llm.py` проверяет границу запроса и параметры DSLab без сетевого вызова.
`test_app.py` проверяет страницу, состояние сервера и безопасный отказ без API-ключа.

Что осталось проверить в первом наборе:

1. контрольные суммы ИНН, ОГРН и ОГРНИП;
2. одинаковая каноническая модель из эквивалентных тестовых данных JSON и CSV;
3. преобразование `$date` и `$numberLong` без потери данных;
4. псевдонимы полей и неизвестные значения перечислений не ломают весь снимок;
5. `GREEN / YELLOW / RED / GREY` без самостоятельного пересчёта цвета;
6. отсутствие данных не превращается в положительный сигнал;
7. каждое фактическое утверждение содержит валидный `evidence_id`;
8. две сессии не видят контекст друг друга;
9. ошибки `empty / partial / unavailable / invalid` дают разные ответы.
